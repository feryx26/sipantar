🌐 API ENDPOINTS (Some Key Examples)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Authentication:
  POST /api/login                        → User login

Commodities:
  GET  /api/komoditas                    → List all commodities
  POST /api/komoditas                    → Add commodity (admin)

Markets:
  GET  /api/pasar                        → List all markets
  POST /api/pasar                        → Add market (admin)

Prices:
  GET  /api/harga                        → Get current prices
  POST /api/harga                        → Input price (enumerator)

⭐ Availability (NEW):
  GET  /api/ketersediaan                 → Get availability data
  POST /api/ketersediaan                 → Add availability (admin/dinas)
  PUT  /api/ketersediaan/:id             → Update availability
  DELETE /api/ketersediaan/:id           → Delete availability

See README.md for complete API documentation.
